# CloudOpsLab

A hands-on DevOps and Cloud Engineering portfolio project.

## Goals

- Version control with Git and GitHub
- Automated builds and tests with Jenkins
- Containerization with Docker
- CI/CD pipeline automation
- Infrastructure as Code with Terraform
- Kubernetes deployment
- Monitoring with Prometheus and Grafana

## Project Status

Phase 1: Project setup and version control.

## Learning Approach

Build each component step by step, verify it works, and document the results.
